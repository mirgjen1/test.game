## Installation

Clone the repository:

```bash
git clone https://github.com/mirgjen1/test.game.git
```

Navigate into the project directory:

```bash
cd test.game
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Or if using standard Node setup:

```bash
npm start
```
